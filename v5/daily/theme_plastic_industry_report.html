熱力圖觀察邏輯

Mason 依產業熱力圖指出「塑膠工業」很熱門，因此以官方產業別 03 建立大主題，並用公司官方產品證據切分小主題。

本版不反推或捏造熱力圖數值；熱力圖只作主題觸發與觀察框架，正式納入仍以 TWSE/TPEx 產業別與公司官方產品證據為準。

  1. 1. 先看是否為整體產業升溫
    綜合石化、上游原料、下游加工若同時轉強，才較像塑膠工業整體輪動。
  2. 2. 再看是哪個小主題帶動
    PVC、PE/EVA、苯乙烯、包材膠帶、合成皮、消費防護的驅動因子不同，不能只用「塑膠工業」四字概括。
  3. 3. 區分資金輪動與基本面改善
    熱力圖熱門可能只是短線資金輪動；需用產品價差、營收、報價與產線狀態確認基本面。
  4. 4. 避免把個股題材誤認為產業題材
    若只有少數低價或特殊題材股轉強，應標記為個股/小主題觀察，不直接升級成整體產業結論。
優先小主題理由
綜合石化 / 塑膠原料判斷是否由大型上游與集團型塑化廠帶動，是整體產業確認層。
PVC / 氯乙烯 / PVC 加工PVC 價差與建材/工業需求易形成明確景氣循環。
包材 / 薄膜 / 膠帶若上游未同步，但此組強，可能是下游加工或包材需求輪動。
合成皮 / 人造皮 / 鞋材車材可觀察鞋材、車材與東南亞產能需求，與上游原料驅動不同。

小主題強化地圖

先判斷是整體塑化鏈輪動，還是 PVC、包材、合成皮等單一子題輪動。

綜合石化 / 塑膠原料

3 檔

塑膠工業的上游與集團型平台，涵蓋 PVC、PE、PP、ABS/PS、聚酯與電材等多條產品線。

代表：1301 台塑、1303 南亞、1326 台化
熱力圖解讀：屬於大主題確認層：若本組與下游加工組同時轉強，代表不只是單一小題材，而可能是塑化鏈整體輪動。
觀察指標
  • 原油 / 石腦油 / 乙烯 / 丙烯成本變化
  • PVC、PE、PP、ABS/PS 價差
  • 中國需求與庫存循環
  • 台塑集團內部不同產品線是否同步

PE / EVA / 聚烯烴

2 檔

聚烯烴樹脂與 EVA 發泡材料，偏材料循環與下游鞋材、包材、工業應用。

代表：1304 台聚、1308 亞聚
熱力圖解讀：若熱力圖只顯示塑膠工業升溫但本組未跟上，可能代表行情偏 PVC、苯乙烯或終端加工；若本組領先，則偏材料價差或 EVA 題材。
觀察指標
  • EVA / LDPE / HDPE / LLDPE 價格
  • 鞋材、太陽能封裝、包材需求
  • 上游乙烯成本
  • 同業開工率與庫存

PVC / 氯乙烯 / PVC 加工

3 檔

PVC 樹脂、PVC 膜材、PVC sheet / rolls 與相關加工材料。

代表：1305 華夏、1321 大洋、4305 世坤
熱力圖解讀：若 PVC 上游與加工廠同時在熱力圖轉強，代表從原料到加工的確認度較高；若只有加工廠強，需查是否為個股或低價輪動。
觀察指標
  • PVC 報價與乙烯法/電石法供給
  • 建材、管材、薄膜需求
  • PVC 加工廠毛利變化
  • 中國房地產/基建需求訊號

苯乙烯系 / ABS / PS / SM

3 檔

SM 上游與 ABS / PS / HIPS / PP / PC / ASA 等苯乙烯系、工程塑膠材料。

代表：1312 國喬、1310 台苯、1309 台達化
熱力圖解讀：若科技族群降溫但本組轉強，需分辨是電子材料需求延伸，還是純原料價差改善。
觀察指標
  • SM、ABS、PS 價差
  • 電子/家電/汽車需求
  • 台苯、國喬、台化產品線是否同步
  • 產線歲修或供給干擾

可塑劑 / 尼龍原料 / 特化

2 檔

可塑劑、CPL / nylon-6 上游與其他塑化特化中間體。

代表：1313 聯成、1314 中石化
熱力圖解讀：若本組明顯領先但大型塑化未動，可能是特定產品價差或個股題材，不宜直接解讀為整體塑膠工業全面轉強。
觀察指標
  • DOP/DBP 等可塑劑需求
  • CPL 與 nylon-6 價差
  • 產線調整與產品組合變化
  • 中國同業供需

合成皮 / 人造皮 / 鞋材車材

4 檔

合成皮、人造皮、鞋材、車用內裝與機能材料，屬下游加工與消費/車材應用。

代表：1307 三芳、1340 勝悅-KY、1341 富林-KY、4303 信立
熱力圖解讀：若熱力圖中塑膠工業熱門主要由此組帶動，解讀應偏下游加工與訂單循環，而不是上游塑化價差。
觀察指標
  • 鞋材與運動用品需求
  • 車用內裝材料訂單
  • PVC/PU 原料成本
  • 東南亞產能與匯率

包材 / 薄膜 / 膠帶

4 檔

塑膠容器、射出成型、薄膜、膠帶、軟性包裝材料等中下游加工。

代表：1323 永裕、4306 炎洲、1324 地球、4304 勝昱
熱力圖解讀：若此組與消費防護同時升溫，可能代表下游加工/民生應用輪動；若同時伴隨上游轉強，才較像完整塑膠鏈輪動。
觀察指標
  • 包材與膠帶需求
  • 原料轉嫁能力
  • 民生消費/物流/工業用量
  • 利基包材或高值化產品占比

再生塑膠 / 循環材料

1 檔

廢塑回收、EVA/PE 循環再利用與再生材料。

代表：1337 再生-KY
熱力圖解讀：若只有本組強，應視為循環材料題材或個股輪動；需等待更多同類公司或產業資料補強。
觀察指標
  • 再生料價格與原生料價差
  • 環保政策與品牌供應鏈要求
  • 回收料來源與品質穩定性
  • 下游發泡材料需求

消費品 / 防護耗材

3 檔

雨衣、防水用品、不織布、醫療/防護耗材、行李箱等終端塑膠製品。

代表：1325 恆大、1315 達新、9950 萬國通
熱力圖解讀：若本組領漲，熱力圖訊號可能偏民生消費或題材輪動，未必代表塑化上游景氣同步改善。
觀察指標
  • 不織布與防護用品需求
  • 旅遊/行李箱消費
  • 通路庫存
  • 原料成本與終端售價轉嫁
