# 綠能環保主題：風電 / 海事工程 / 複材材料

## 定位與邊界

- 中立主題情報資料庫；不混入 Mason 持股，不作買賣建議。
- 官方產業別 35 只作母體錨點；正式標籤依公司官網 / TWSE 可追溯資料。
- ETF 成分股不作本批唯一貼標依據；本批未使用 ETF 成分股作分類依據。
- 營收曝險未揭露時使用 qualitative / unknown，不自行估算。

## 本批正式納入

### core
- `2072 世紀風電`（high）：離岸風電水下基礎 / 大型鋼構供應商。世紀風電官網工程實績直接列沃旭大彰化離岸風場水下基礎 Pin Pile、彰芳西島 Jacket、Monopile 與台電二期水下基礎等專案，屬風電 / 海事工程小題核心。
- `7786 東方風能`（high）：離岸風電海事工程 / 海纜施工與運維服務商。東方風能官網明確定位為台灣海事工程商，服務頁列離岸風電與維運、SOV/CTV、海纜維護與維修、BOP 管理與維護；海底電纜頁列海纜運輸、安裝、埋設、維護與維修，屬本小題核心。

### adjacent
- `3708 上緯投控`（high）：風電葉片材料 / 可回收複合材料供應商。上緯官網列高性能樹脂、風電葉片用材料與可回收熱固樹脂；離岸風電紀錄頁亦說明其跨足碳纖維複合材料、為風機大廠合格供應商。因屬材料供應，不是海事工程本體，列 adjacent。

## 暫緩 / 未納入

- 本批只處理官方母體中候選子題為 `風電 / 海事工程 / 複材材料` 的 3 檔；未因綠能環保官方產業別把其他待正式分類公司直接納入。
