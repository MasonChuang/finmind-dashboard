# 綠能環保主題：循環經濟 / 資源回收 / 再生材料

更新時間：2026-07-15T12:00:00+08:00

## 定位與邊界

- 中立主題情報資料庫；不混入 Mason 持股，不作買賣建議。
- 官方產業別 35 只作母體錨點；正式標籤依公司官網 / TWSE / TPEx 可追溯資料。
- 營收曝險未揭露時使用 qualitative / unknown，不自行估算。

## 本批正式納入

### core
- `6581 鋼聯`（high）：鋼鐵集塵灰資源化 / 粗氧化鋅再生材料供應商。官網直接列粗氧化鋅、旋轉窯製程與可收受廢棄物 / 資源物，循環經濟證據清楚。
- `6887 寶綠特-KY`（high）：再生塑膠 / PET 回收清洗與再生材料垂直整合平台。官方首頁直接揭露回收產業鏈、瓶片清洗、造粒、化纖紡絲與再生塑膠原料。
- `7610 聯友金屬-創`（high）：鎢 / 鈷金屬回收與二次硬質合金資源化供應商。官網直接說明以專利技術回收提取鎢、鈷金屬並打造閉環式循環經濟供應鏈。
- `8390 金益鼎`（high）：貴金屬 / 電子廢棄物回收處理與精鍊服務商。官網直接列貴金屬回收、拆解分選、電析精鍊與太陽能板回收，屬本小題核心。
- `8423 保綠-KY`（high）：廢輪胎循環經濟 / 再生橡膠材料供應商。官方首頁直接標示廢輪胎循環經濟與回收再利用，產品為再生橡膠材料。
- `9955 佳龍`（high）：貴金屬 / 廢資訊品回收與廢液處理服務商。官網直接列貴金屬回收、廢資訊品回收與廢液處理，列本小題 core。

### adjacent
- `8341 日友`（high）：醫療 / 事業廢棄物處理與熱能回收 adjacent 服務商。廢棄物處理證據明確，但主軸是清除處理與焚化，資源回收 / 再生材料屬相鄰而非本小題 core。
- `8473 山林水`（high）：水處理 / 廢棄物資源化 / 生質能源 adjacent 環工平台。官網直接列廢棄物資源化、底渣處理與回收再利用；因公司同時是水處理環工平台，保守列 adjacent。

## 暫緩 / 未納入

- 8476 台境*：官網可讀頁面仍偏舊且本輪未取得足以支撐資源回收 / 再生材料貼標的正式產品證據，暫緩。
- 9930 中聯資源、8438 昶昕、6969 成信實業*-創、8422 可寧衛*、4924 欣厚-KY：不在本批原候選小題或需要另行查證，未因官方產業別直接納入。
